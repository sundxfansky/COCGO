# 项目审查与优化记录（2026-09-21，历史记录）

本文记录旧版网络 Root 服务的审查结果。当前实现已将文件、Shell 和触摸迁移到宿主 APK 的私有 Root 管道，旧服务条目仅用于追溯变更背景。

本次对 Android/Kotlin、Compose 配置状态、动态 JAR 加载与构建、Root 服务协议、Rust/JNI、Go 云端及 React 页面进行了静态扫描，重点检查配置读写、并发、取消、持久化和原生内存边界。不是逐个游戏场景的真机验收，也不是性能基准测试。

## 已完成的修复

| 优先级 | 原问题与触发场景 | 本次修改 | 主要文件 |
| --- | --- | --- | --- |
| P1 | WebSocket 启动回复被当作业务请求结果；普通 JSON 文件读取可能覆盖配置 | 保留两条启动请求并行发送，等待按序回复后再发送业务请求；只有启动配置回复参与初始化 | ServerActions.kt、InitConfigs.kt |
| P1 | 已取消或超时请求的迟到回复命中下一请求；协程取消被吞掉 | 传播取消；对已发送的取消请求重建内部 Root 管道；隔离旧工作进程回复；发送失败立即返回；关闭时释放等待者 | ServerActions.kt、LocalActionTransport.kt |
| P1 | 配置写入失败仍刷新内存、关闭设置窗口 | 服务器确认保存成功后才更新缓存和执行成功回调；失败保留编辑界面并用 ShowMessage 提示 | SchemaExporter.kt、ConfigManager.kt |
| P1 | 云端配置仅更新内存，重启丢失 | 通过本机 WebSocket 落盘成功后才确认版本、通知 UI；失败重试；停止同步时取消 OkHttp 请求 | CloudConfigSync.kt |
| P1 | Release keep 规则使用旧包名 com.coc.zkqcode | 修正宿主包名，保护动态加载的插件入口 | app/proguard-rules.pro |
| P1 | Rust 取色缺少尺寸、stride、容量和偏移数组校验，可能越界或 panic | 检查 RGBA 可读容量和完整三元组；坐标 checked_add；原始缓冲区使用非对齐读取 | rust_logic/src/color/ |
| P1 | 后端忽略配置写入错误；并发时响应版本可能属于另一次写入 | SQLite RETURNING 原子取得本次版本，失败返回 500；拒绝缺失/null 配置与非字符串值 | backend/main.go |
| P1 | 邮箱验证更新失败仍返回成功，验证与重发之间存在竞态 | 更新时匹配验证码、有效期，检查错误和实际更新行数 | backend/main.go |
| P2 | check_exists 返回 success + false 被解释为文件存在 | 同时检查返回数据 | FileHelper.kt |
| P2 | 网页保存期间继续编辑，新草稿随后被轮询覆盖 | 编辑修订号保留新草稿，忽略旧轮询结果 | web/src/main.jsx |
| P2 | 截图取消被误判为 MediaProjection 故障，开启永久 Shell 回退 | 单独传播 CancellationException | ScreenCaptureManager.kt |

新增 ServerTransport 用于无设备消息次序/取消测试；Rust 纯搜索与布局校验模块支持开发机直接测试。外部配置文件现由宿主 Root 工作进程通过私有标准输入输出管道访问。

## 第二轮修复：原待处理项已落实

| 原问题 | 已完成修改 |
| --- | --- |
| 热更新选错产物、父加载器遮蔽、加载失败无法回退 | 统一版本解析；兼容旧 ChaCha20 包装；RSA 签名同时覆盖版本文件名与密文；插件命名空间严格独立加载；失败保留原实例及配置；停止并等待旧脚本后再激活新版 |
| 宿主直接引用插件 Schema | MainCode 增加配置刷新接口，宿主只调用当前插件；内置入口通过反射加载 |
| Root 服务全接口监听且免认证 | 移除网络监听和独立服务 APK；宿主只通过私有管道启动 Root 工作进程，关闭管道时回收命令及子进程 |
| 验证码与会话保护不足 | 账号/来源限流；持久化验证码尝试预算；随机会话仅存摘要，30 天到期，可注销；旧 Token 7 天迁移窗口且可立即撤销 |
| 构建/发布路径硬编码与先删旧产物 | SDK 路径自动解析；D8 包含完整依赖 classpath；临时产物成功后原子替换；提供跨平台签名/上传脚本及云端发布接口 |
| adb 热部署删除通配路径且忽略错误 | 统一设备参数；使用唯一临时文件；每步检查退出码；Debug 广播要求系统 DUMP 权限，Release 禁用 |
| 非私有文件绕过宿主 Root 通道 | 脚本命令统一经过内部 shell_action；文件操作使用宿主 Root 工作进程；启动前守护脚本写入私有目录；存档名拒绝路径穿越及命令插值 |
| 截图/服务资源生命周期 | 截图管道轮询读取有截止时间，停止时销毁进程并消费 stderr；限制 PNG 总量；Root 命令有时间/输出上限；DaemonService 取消协程并关闭连接 |
| 触点并发与 Bitmap 所有权 | 触点状态和服务器确认串行；新脚本等待旧脚本清理；失败释放可重试；Bitmap 调用方获取独立副本，缓存不再回收仍可能被读取的对象 |
| 云同步覆盖草稿、多设备互相覆盖 | Android 待处理区显式选择云端或本地；记录已处理版本；同步改由进程管理；后端 If-Match 乐观锁，网页保留草稿并提供冲突合并操作 |
| 构建性能和依赖可复现性 | Rust inputs/outputs 与按需 ABI；删除空清理任务；保留旧 C++ 源码但停止打包；锁定前端版本并声明 ESM |

发布密钥、API 配置和旧客户端迁移步骤见 [PLUGIN_RELEASE.md](PLUGIN_RELEASE.md)。生产签名私钥应由发布方保管；缺少可信公钥时拒绝远程更新。

## 验证记录

- Android JVM 测试：23 个通过，包括插件初始化失败时恢复被删除/替换的配置状态；Root 服务 JVM 测试：5 个通过，包括原子写入失败保留旧文件、静默子进程不拖住管道。
- Debug APK、Release APK（含 R8）、独立插件 JAR 均构建通过；四种 ABI Rust 库均装入 APK，旧 native-lib 不再打包；未变更 Rust 任务显示 UP-TO-DATE。
- Android Lint 已完成，0 个错误；仍有依赖新版本提示、资源/KTX 建议和 Root 应用电池策略等非阻塞警告，未为消除提示而盲目升级依赖。
- `go test -race ./...`、`go vet ./...` 通过，覆盖版本冲突、会话到期/撤销、旧 Token 迁移、验证码预算、签名版本绑定及无权限发布。
- Rust 4 个边界测试、Python 2 个加密格式测试和网页生产构建通过。
- 隔离云端 smoke 通过：使用真实构建 JAR 完成签名、管理员上传、下载、解密一致性验证；旧版本配置写入返回冲突；注销 Token 立即失效。测试数据库与私钥均使用临时目录并已清理。
- 已连接 Android 设备上的独立 app_process smoke 通过：两个插件版本与宿主同名类正确隔离、真实插件入口加载、宿主 ABI 共享；匿名 HTTP 被拒绝，认证 HTTP/WebSocket、原子文件写入及 shell RPC 正常。未安装、停止或启动设备现有应用。
- 设备未授予 adb shell 的 su 权限，所以设备 smoke 使用 shell 身份。真实 Root 触摸、游戏存档替换、MediaProjection 与悬浮窗完整流程仍需在已授权环境验收，不能将协议 smoke 等同于游戏自动化验收。

本次涉及宿主、动态接口和 Root 服务升级，需要重新安装宿主 APK并升级云端；仅替换 JAR 不足以交付修复。改动保留在工作区，未发布到任何现有线上服务。
