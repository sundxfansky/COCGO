# QQ 授权登录使用与实现

2026-10-18：完成宿主和插件接入，并在 `127.0.0.1:5555`（Android 13、Root）验证授权采集、账号绑定、重放及国服登录。切号仅重置国服账号存档，保留资源目录。

## 使用

1. 安装此次构建的宿主 APK，并授予宿主 Root 权限。宿主内置“QQ授权工具v1.4”；发起 QQ 授权或登录时，若当前用户尚未安装，自动通过宿主 Root 管道安装并校验签名及授权入口，无需单独准备安装包。授权工具与正式 QQ 包名相同，遇到已有正式 QQ 或其他用户的同包名安装冲突时停止，不自动卸载或覆盖。
2. 进入“主页设置 → QQ 全局授权库”，通过加减号或直接输入选择授权序号，例如 `1`。有效序号会立即保存，切换页面或重启后仍保留。
3. 点击“获取 QQ 授权”，在工具中完成本人登录或扫码。成功后，授权保存在全局授权库的该序号下，主页显示剩余有效时间。
4. 点击“使用此授权登录”，复用该序号的有效授权，仅重置国服账号存档并启动国服。授权缺失或过期时会提示回到全局授权库获取，不会自动打开扫码页。
5. 在“账号设置”点击对应账号的“配置”，进入独立详情页，选择“国服 → QQ 授权登录”，再选择“复用 QQ 授权序号”。选择登录方式不会弹出授权工具；多个账号可选择同一序号。序号立即保存，其他账号设置通过“保存配置”或主页底部按钮保存。有效时间按天、小时、分钟显示，并每分钟刷新。

## 账号配置界面

“提取存档”已合并到“账号设置”，可以展开操作。账号列表每行仅显示只读备注、启用开关、“上号”和“配置”。“上号”使用该账号当前选择的存档、直接启动或 QQ 登录方式，不启动自动任务；存档缺失或复制失败时取消上号。

点击“配置”打开独立页面，顶部左右箭头快速切换账号。备注、游戏版本（国服／国际服）、登录方式及相关存档或授权序号均在此编辑。主世界和夜世界分别有总开关，关闭后对应设置保留并置灰，执行时跳过该世界的任务。

每个账号独立保存全部世界设置和建筑优先级，原“配置文件1/2”标签及方案分配入口已移除。首次读取旧配置时，按照账号原先绑定的共享方案复制为各自的配置，保留原“不打夜世界”的状态；保存后不再重复迁移。账号间复用 QQ 授权不会共享世界设置。

运行日志改为屏幕下方约 55% 高度、横向铺满的黑色半透明浮层，使用白色小号等宽字体和紧凑行距。默认触摸穿透，点击“浏览日志”后可滚动；自动触摸和截图期间仍保持输入与画面保护。

“顶号后选项”的切号方式改为“切号并计时等待”，默认只让被顶账号冷却 3 分钟，可修改为 1～1440 分钟。冷却期间继续运行其他启用账号；所有启用账号都在冷却时，显示倒计时并等待最早恢复的账号。冷却计时使用当前插件运行期内的单调时钟，不受设备系统时间调整影响。“立刻重连”和“原地等待”选项保留。

原“启动手动切号模式”页面及主页、悬浮控制栏的入口已删除，手动登录统一使用账号列表内各账号的“上号”按钮。

## 多账号自动轮换

例如先在全局授权库保存授权 `1`、`2`。账号 `1` 和 `3` 的“复用 QQ 授权序号”均设为 `1`，账号 `2` 设为 `2`，即可按 `1 → 2 → 1` 复用授权。每个账号详情显示其引用授权的状态；更新授权 `1` 后，所有引用它的账号直接使用更新后的授权。

启用这些账号并保存运行后，现有轮换顺序按每个账号保存的授权序号读取全局库。每次登录都会停止授权工具、同步选定授权到工具的私有偏好和外部输入文件，并回读校验外部输入，避免上一个账号的缓存被继续使用。外部输入校验失败时不会清除国服存档或启动登录。

自动轮换只使用已保存且未过期的授权。某个账号引用的授权缺失、损坏或过期时，会提示该授权序号并跳过本轮，其他启用账号继续轮换；在全局授权库中重新获取该序号的授权后，后续轮换自动恢复。只有主动点击“获取 QQ 授权”才会打开工具完成首次授权或更新授权。

授权库序号独立于账号编号。更改主页的授权库序号只选择要管理的授权，不会修改账号的引用。旧版本升级时，各账号的授权引用默认沿用原账号编号，保留既有授权对应关系。

## 登录行为

“使用此授权登录”及使用 QQ 方式的主循环会停止国服游戏，仅删除其私有 `shared_prefs` 和 `databases` 账号存档目录。私有 `files`、`cache`、`save`、`update` 及外部资源目录均保留；游戏仍可能自行下载必要的更新。工具校验、游戏入口校验、授权解析和工具数据准备均先于清除操作；授权过期时不清除游戏。

工具交回凭据不代表服务器登录成功。程序优先使用固定坐标的多点颜色识别，在已验证的国服横屏布局上自动点击协议“同意”、勾选协议框和点击 QQ 登录。每次操作都重新获取画面，Root 输入进程在触摸注入时验证游戏仍在前台；识别到绿色勾选但按钮已变灰时等待，不会重复取消勾选。检测到 QQ 授权工具进入前台后立即停止点击；其他应用抢占前台也停止，但不视为授权成功。如果工具在两次检查之间已返回，则在确认已识别的登录页持续消失后结束点击，仅表示已发起登录。

布局比例不兼容，或连续 6 秒未命中固定颜色时，回退到宿主现有 OCR 和原生控件树，识别游戏包内明确的登录和切换账号控件。OCR 同意协议仍要求匹配“用户与隐私相关协议指引”标题及“同意”“不同意”两个按钮。整个流程最长 120 秒；QQ 按钮最多重试三次，至少间隔一秒。游戏启动时若意外退出，会尝试重新打开一次，不会重复清理存档。

手动打开授权模块会暂停自动运行；操作完成后需要由用户恢复运行。设置悬浮窗在授权期间临时隐藏并释放触摸，保留未保存的设置。

## 登录速度

当前快速路径采用 `QqLoginColors` 的固定坐标和多点颜色特征，按 1280×720 基准缩放，仅适用于相同 16:9 布局，其他布局走回退。协议页同时检查面板、顶部和两个绿色按钮；登录页检查 QQ 图标、按钮颜色和勾选框。每轮额外等待 80 毫秒，截图和前台检查本身也需要时间，因此这不代表每 80 毫秒必定完成一轮。点击复用宿主已有的 Root 触摸管道，省去每次启动 `input tap` 的开销。相同按钮设有防抖间隔，下一步不同按钮可以立即处理。

## 宿主与动态插件

宿主新增 `core/qq` 包和 Manifest 注册的内部 Activity，负责：

- Activity Result 回调、取消、超时及旋转恢复。
- 校验授权工具签名，防止误操作同包名的正式 QQ。
- 工具缺失时从 `assets/qq/authorization-tool-v1.4.apk` 释放到私有缓存，校验固定 SHA-256 后通过 Root 执行显式禁止覆盖的 `pm install -R --user <当前用户>`，由标准输入传入安装包；结束后清理缓存，安装失败时停止本次授权或登录。此能力需要更新宿主 APK，仅热更新插件不能加入内置安装包。
- 按独立的全局授权序号保存到 `noBackupFilesDir/qq_authorizations`，避免凭据进入普通设置和 Android 备份；账号配置仅保存引用序号。
- 通过现有 Root stdin/stdout 管道设置工具模式、偏好缓存及 `aw_temp.txt`，保持两种输入一致。Root worker 进入系统挂载命名空间，才能在 Android 13 的包隔离下读写真实授权工具数据。
- 校验游戏入口、清除旧会话、启动游戏并尝试点击明确的 QQ 登录入口。

插件新增主页模块及国服启动方式 `2`。该选项原本是不可选的旧“上号器”占位，此次实现替换其 UI 分支；旧 `data_content` 普通配置不会自动导入为 QQ 授权。

必须同时更新宿主 APK 与插件。新插件依赖新增宿主 API，单独热更新 JAR 到旧宿主不能使用。新安装没有外部插件时会使用 APK 内置代码；已有设备若保留旧的版本号 JAR，加载器会优先选它，需要部署新的插件。

构建：

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:buildJar
```

输出：

- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/plugin/code.jar`

已有设备可在安装新版宿主后使用项目现有的 `:app:deployAndReload` 任务部署新插件；设备测试中已运行该任务。其 Root 命令引号也已修正。

本轮全局授权库与启动 UI 验证：63 项单元测试、5 项 Android 设备测试通过，宿主 APK、测试 APK 与独立动态 JAR 构建通过。设备上确认冷启动自动打开主页、全局和账号引用序号的加减切换即时保存，选择 QQ 启动方式不会打开授权工具。清除回归使用隔离私有目录和模拟 Root 传输，验证所有授权序号删除及工具缓存清除命令，不清空真实设备授权。

宿主“清除全部数据”会暂停运行和云同步，删除整个私有授权库、普通配置及存档数据，并通过现有 Root 后端清空已验证授权工具的数据（含偏好与 WebView 会话），删除共享存储的 `aw_temp.txt`。工具未安装时仍删除外部授权文件；同包名的正式 QQ 不会被清空。清除失败会提示重试，成功后退出辅助。此操作删除本地授权凭据，不撤销腾讯服务端授权。
